# Panagiota Bakratsa Website

Official website for Panagiota Bakratsa, Psychologist - Psychotherapist in Kavala, Greece.

Live site: https://psychologosbakratsa.gr

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Cloudflare Workers & Pages

## Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Deployment

The project is connected to GitHub and deployed through Cloudflare Workers & Pages.

Pushes to the `main` branch trigger a production deployment.

## Accessibility

The website was developed with accessibility in mind and tested using WAVE, keyboard navigation, reduced-motion preferences, responsive layouts, and browser zoom.
